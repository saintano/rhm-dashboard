# Design
Существующий светлый рабочий интерфейс. Arial для управления, Georgia для названий. Фон #F7F7F7, основной синий #1E3A5F. Сохранять цветовые обозначения задач и исполнителей.
Неделя 60px, заголовок колонки 120px, колонка 310px. Масштабы 100/75/50%. Фиксированная геометрия использует border-box. Текущая неделя выделена красным фоном шкалы, текстом «сейчас» и контуром строки поверх задач без перехвата событий мыши.
Окно снапшотов использует существующие кнопки, светлый фон, список с датами и состояниями загрузки/ошибки. Длинные названия переносятся.
