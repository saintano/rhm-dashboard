# RHM Market Gantt

Дашборд распределения работ RHM MP 1.0. React 18 + Vite, общие именованные снапшоты в Vercel Blob.

## Работа с планом

Кнопка **Снапшоты** открывает сохранение текущего плана и список общих версий. Введите название и нажмите **Сохранить текущий план**. Для восстановления выберите версию и подтвердите загрузку. Загрузку можно отменить кнопкой **Откат**. Одинаковые названия создают отдельные версии, существующие снапшоты не перезаписываются.

Рабочие изменения автоматически сохраняются в текущем браузере. Они становятся доступны другим участникам только после создания снапшота. На новом устройстве открывается последний общий снапшот; существующий локальный план имеет приоритет. Доступ по ссылке без пароля, по решению владельца. API позволяет читать и создавать версии; удаления и перезаписи нет.

При открытии и изменении масштаба дашборд переходит к текущей неделе. Кнопка **Текущая неделя** возвращает к ней вручную. Шкала и полоса во всех колонках совпадают, заголовки исполнителей закреплены. Нумерация недель соответствует ISO, включая 53-ю неделю.

## Локальная разработка

Требуется Node.js 22 или новее.

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

Открыть http://127.0.0.1:5173. Локальный сервер хранит снапшоты в `.local/snapshots/`, отдельно от общих рабочих версий Vercel. Данные переживают перезапуск сервера. Путь можно изменить через `RHM_LOCAL_SNAPSHOTS_DIR`. Каталог исключён из Git.

```sh
npm test
npm run build
```

`npm run preview` показывает статическую сборку без API. Для полного локального сценария используйте `npm run dev`.

## Публикация

GitHub: https://github.com/saintano/rhm-dashboard

Сайт: https://rhm-dashboard-orpin.vercel.app

Push в `main` запускает существующий автодеплой Vercel. Публиковать весь проект, включая `api/`, `server/`, `shared/` и зависимости, а не только `Dashboard.jsx`.

На Vercel `/api/snapshots` использует private Blob store `rhm-dashboard-snapshots`. `BLOB_READ_WRITE_TOKEN` установлен через подключение Storage. Токен используется только сервером; `.env.local` и `.vercel/` исключены из Git. Vite не передаёт его в клиентскую сборку. Доступ к снапшотам осуществляется через API без пароля. Исходный рабочий JSON хранится в Blob и локальной папке, в публичный репозиторий не включён.

**Не повышать APP_VERSION:** ключ `dashboard-state-v4` содержит рабочие данные команды. Сброс очищает только текущий план и не удаляет общие снапшоты.

Сервер проверяет структуру входящих данных, ограничивает JSON до 1 МБ, названия до 80 символов, отклоняет неподдерживаемые методы и запросы из другого origin. Локальные тесты не записывают данные в production.
